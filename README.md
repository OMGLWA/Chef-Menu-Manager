# Chef's Menu Manager - Part 2

A React Native mobile application designed for restaurant managers and chefs to easily create and manage menu items.

---

## 📱 Features Built in Part 2

* **User Interface:** Clean, user-friendly layout styled with React Native components.
* **Capture Menu Information:** Form inputs allowing the chef to enter the dish name, description, course (Starter, Main, Dessert), and price.
* **Display Menu Items:** Dynamic list that updates automatically whenever a new menu item is saved.
* **User Experience:** Form validation for required fields, error alerts, and clear confirmation messages upon adding a dish.
